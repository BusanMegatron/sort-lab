# SortLab

A C++ desktop app for visualizing sorting algorithms.

Started this project because understanding an algorithm on paper and actually seeing how it works are two different things.

## What it does

- Takes custom arrays of integers
- Validates user input
- Lets you choose a sorting algorithm
- Implements Bubble Sort with step tracking

## Tech stack

`C++` `Win32 API` `MinGW-w64` `VS Code`

## Run locally

Requires Windows and a MinGW-w64 C++ compiler.

```bash
g++ main.cpp -o SortLab.exe -mwindows -static
```

Run in PowerShell:

```powershell
.\SortLab.exe
```

I'm currently studying algorithms and data structures, and wanted to build something that would help me understand sorting beyond just memorizing the code.
